VYAPAROS LOGIN + DASHBOARD FRONTEND

Files:
- index.html
- css/styles.css
- js/app.js

Run in VS Code:
1. Extract this ZIP.
2. Open the extracted VyaparOS-Login-Upgrade folder in VS Code.
3. Install the "Live Server" extension if you do not already have it.
4. Right-click index.html -> Open with Live Server.
   Or use the VS Code terminal:
   npx serve .
   Then open the local URL shown in the terminal.

Important:
- Login/register is a FRONTEND PROTOTYPE. It validates the form and opens the dashboard.
- It does not create real accounts or verify passwords. Passwords are not stored.
- Connect Firebase Authentication or a secure backend before using real accounts.
- Dashboard figures and business records are sample data.
- Invoice upload, OCR, AI task execution, GST filing, phone calls, and bank integrations are not connected.
